`prelum-audit`, `prelum-content` and `prelum-chart-audit` escape a crawled value before printing it as a GitHub annotation, so a newline in a page's text can no longer start a workflow command of its own. `markdownCopies` builds `/llms-full.txt` as an anonymous visitor (the first requester's Cookie and language no longer reach the shared cached file), drops `Set-Cookie` from a Markdown copy, and follows a sitemap index one level only. `prelum-chart-audit` caches its install in the user's own `~/.cache`. `escapeBibtex` no longer escapes the braces of a backslash twice, `srtToVtt` keeps a cue whose text is only digits, and a link-icon host that could not be reached is not stored as having no icon.
